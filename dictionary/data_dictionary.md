# Data dictionary

Generated by `pipeline/05_dictionary.py` from
[definitions.csv](definitions.csv); edit that file, not this one.
Each column links to the rule that defines it. Raw tables hold FDA's values
unchanged (all text); FDA's own field descriptions are in the `ASC_NTS` file of
each quarterly ZIP.

| Table | What it holds |
|---|---|
| [`raw.demo`](#rawdemo) | Raw DEMO rows: one per report (patient and report details), exactly as FDA published them. Every value is text. |
| [`raw.drug`](#rawdrug) | Raw DRUG rows: one per drug listed on a report. |
| [`raw.reac`](#rawreac) | Raw REAC rows: one per reaction (adverse event) term on a report. |
| [`raw.outc`](#rawoutc) | Raw OUTC rows: one per serious outcome code on a report. |
| [`raw.indi`](#rawindi) | Raw INDI rows: one per indication (reason for use) of a drug. |
| [`raw.ther`](#rawther) | Raw THER rows: therapy start and end dates of a drug. |
| [`raw.rpsr`](#rawrpsr) | Raw RPSR rows: who sent the report to FDA. |
| [`raw.deleted`](#rawdeleted) | Case numbers on FDA's deleted-case lists (in each ZIP from 2019 on). Every listed case is removed from the study. |
| [`raw.load_log`](#rawload_log) | One row per quarter and file loaded: the loader's own record, used by verification. |
| [`drug_classes`](#drug_classes) | Every distinct (`prod_ai`, `drugname`) pair in the data that the drug map classifies as an ADHD medicine. |
| [`cases`](#cases) | One row per kept case 2012Q4-2026Q2 across both databases: clean demographics, study group, event flags, serious outcomes and RQ3 predictors. |
| [`rq1_cases`](#rq1_cases) | RQ1 dataset: one row per study-group case (rows of `cases` with a `rq1_group`). |
| [`rq1_counts`](#rq1_counts) | RQ1 count table: kept cases per group x age band x sex x COVID window, with event counts. No case rows. |
| [`rq1_terms`](#rq1_terms) | RQ1 term table: how many stimulant and nonstimulant cases list each reaction term (for the most frequently reported terms). |
| [`rq2_cases`](#rq2_cases) | RQ2 dataset: one row per study-group case with a valid receipt date. |
| [`rq2_monthly`](#rq2_monthly) | RQ2 time series: cases and event counts per study group and month, January 2018 to February 2026. |
| [`rq3_cases`](#rq3_cases) | RQ3 dataset: study-group cases of the 2022-2026 database with the serious-outcome target and predictors, split by time. |
